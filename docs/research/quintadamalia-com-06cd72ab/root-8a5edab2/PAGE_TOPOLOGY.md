# Quinta D. Amália page topology

1. Fixed navigation overlay — logo, pill navigation, social links, responsive menu.
2. Hero — dark canvas, large editorial headline, glow, CTA, perspective image collage.
3. Partner strip — monochrome project logos.
4. About — split image/text section on the light canvas.
5. Gallery — dark perspective carousel-like composition with central experience metric.
6. Stats — three-column proof strip.
7. Apartments — dark four-card apartment/product grid.
8. Lifestyle intro — editorial heading and positioning copy.
9. Lifestyle amenities — ruled list with tags, hoverable CTA.
10. Masterplan — full-bleed aerial visual with gradient caption.
11. Contact — black CTA block, giant heading, local demo form.
12. Footer — logo and compact metadata.

The page uses one document scroll container. Navigation is fixed; section content remains in normal flow. Interactive behavior is scroll-driven for reveal and counters, hover-driven for image/card feedback, click-driven for navigation/menu/form, and CSS animation-driven for the gallery cards. `prefers-reduced-motion` removes non-essential movement.
