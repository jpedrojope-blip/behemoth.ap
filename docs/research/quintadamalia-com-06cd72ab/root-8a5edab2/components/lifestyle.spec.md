# Lifestyle specification

## Overview

- Target file: `index.html`, `.lifestyle` in `styles.css`
- Interaction model: scroll reveal + hoverable pill/arrow affordances
- Visual: light canvas, large serif intro, seven ruled amenity rows with tags.

## Content

Heated indoor pools & private spa; State-of-the-art gym; 24/7 concierge & security; Smart-home technology; Sustainable design; Panoramic terraces; Exquisite craftsmanship.

## Responsive behavior

Desktop uses intro/sidebar plus list. Tablet stacks intro above list. Mobile collapses each row to a single column and hides the optional circular arrow on non-primary rows.
