# About specification

## Overview

- Target file: `index.html`, `.about` in `styles.css`
- Interaction model: scroll reveal + anchor CTA
- Visual: light paper canvas, editorial split layout, one tall residence image, restrained copy column.

## Content

Uses the live page copy for the about section, including the project description, T1/T2/T3 offer, Carrara marble, Gaggenau kitchens, smart-home technology, and Q4 2026 construction detail.

## Assets

`home-1.jpg` for the project image; `about-shape.png` remains available for future decorative use.

## Responsive behavior

Desktop is a two-column split. Tablet/mobile stack media above copy and keep paragraphs measure-controlled.
