# Hero specification

## Overview

- Target file: `index.html`, `.hero` in `styles.css`
- Interaction model: scroll-driven parallax + anchor CTA
- Visual: dark full-viewport canvas, centered oversized white serif headline, soft lime/peach radial glow, bottom image collage.

## Content

- Eyebrow: `Welcome to Quinta D. Amália`
- Heading: `Where luxury meets serenity`
- CTA: `Say hello`
- Supporting cue: `Scroll to explore`

## Assets

`home-1.jpg`, `home-15.jpg`, `home-5.jpg`, `home-16.jpg`.

## Responsive behavior

Desktop centers the headline and places four angled image cards along the bottom edge. Tablet keeps the same composition with a collapsed menu. Mobile narrows cards and reduces the hero type scale; cards remain decorative, not interactive.
